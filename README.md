# Task Manager

Навчальний pet-проєкт для практики розробки застосунків на React і TypeScript.

## Можливості

- створення задач;
- редагування задач;
- видалення задач;
- позначення задач як виконаних;
- фільтрація задач за статусом.

## Технології

- React
- TypeScript
- Vite

## Запуск проєкту

```bash
npm install
npm run dev
```

Після запуску застосунок буде доступний за адресою, яку вкаже Vite у терміналі.

## Навчальні цілі

У межах проєкту відпрацьовуються:

- декомпозиція інтерфейсу на компоненти;
- робота зі state та props;
- типізація даних у TypeScript;
- обробка подій і форм;
- організація структури React-проєкту.
